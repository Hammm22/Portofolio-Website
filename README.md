# Portofolio Website: Ilham Dwi Arsandy (`Hammm22`)

Situs web portofolio interaktif milik **Ilham Dwi Arsandy (`Hammm22`)**, siswa SMK Jurusan **PPLG (Pengembangan Perangkat Lunak dan Gim)** yang berfokus pada pengembangan aplikasi Web Interaktif (React, Next.js, Laravel) dan Mobile (Flutter, Android Java).

## Stack Teknis
- **Framework:** Next.js (App Router, JavaScript)
- **Styling:** Tailwind CSS + CSS Custom Properties (`src/app/globals.css`)
- **Animasi & Scroll:** GSAP (`@gsap/react`, `ScrollTrigger`, `Flip`, `MotionPathPlugin`), Three.js (Hero desktop lazy-load), & Lenis Smooth Scroll
- **Ikonografi:** Phosphor Icons (`@phosphor-icons/react`) & ikon SVG stack teknologi (`src/components/ui/TechStackIcon.jsx`)
- **Tipografi:** `Syne` (Display), `Plus Jakarta Sans` (Body), `JetBrains Mono` (Metadata Teknis)

## Menjalankan Proyek Secara Lokal

```bash
# Menjalankan server pengembangan
npm run dev

# Memeriksa kualitas kode (ESLint)
npm run lint

# Menjalankan unit test built-in Node
npm test

# Membangun aplikasi untuk produksi
npm run build
```
